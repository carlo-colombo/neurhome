# DiceBear avatar styles

These files are unmodified style definitions from `@dicebear/styles` 10.6.0
(<https://www.dicebear.com>), rendered on-device by the app's own DiceBear
interpreter. Each style keeps its upstream license; the text below is copied
verbatim from each definition's `meta.license.text`.

Keep this file in sync when adding or removing a style: it is generated from
the definitions themselves, so the license can never be forgotten.
